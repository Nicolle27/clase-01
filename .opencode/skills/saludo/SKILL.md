## Instrucciones

1. Identifica cuando el usuario pide un saludo.
2. Responde en español de manera amable.
3. Mantén la respuesta breve y natural.
4. Pregunta cómo está el usuario si resulta apropiado.
5. No ejecutes comandos para responder un saludo.
