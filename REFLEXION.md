# Reflexión de la clase 01

1. En esta práctica aprendí a utilizar OpenCode desde Visual Studio Code.
2. Creé un skill llamado `saludo` para personalizar la respuesta del asistente.
3. El archivo `SKILL.md` contiene las instrucciones para responder de manera amable y breve en español.
4. Organicé el skill dentro de la carpeta `.opencode/skills/saludo/`.
5. Aprendí a revisar los archivos del proyecto mediante la terminal.
6. Utilicé el comando `ls -la` para visualizar los archivos y carpetas.
7. Utilicé el comando `find` para comprobar la ubicación de los archivos.
8. Revisé las instrucciones del skill con el comando `cat`.
9. Probé OpenCode escribiendo el prompt `salúdame`.
10. Durante la configuración apareció un error relacionado con las credenciales y la compatibilidad del modelo.
11. Revisé el problema y continué con las pruebas hasta obtener una respuesta de saludo.
12. Comprobé que OpenCode podía responder siguiendo las instrucciones del skill.
13. Antes de ejecutar comandos, es importante revisar qué acciones realizarán.
14. También aprendí a registrar los resultados mediante capturas de pantalla y archivos Markdown.
15. Esta práctica me ayudó a comprender mejor cómo configurar y utilizar un asistente de programación.
